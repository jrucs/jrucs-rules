# jrucs-rules

JRUCS Reconfigurable Universal Card System (JRUCS) is for playing trading card games.

## Packaging

The cards are Tarot size (2.75" x 4.75").  This gives a lot of room for art.  These cards are intended to be shuffled.

Decks can be other sizes and aspect ratios, for instance landscape.  Varied formats and backs are encouraged.  Different format decks can play one another.  Decks might even mix formats.  Rules are intended to be fluid and neogotiable.

Rarity exists solely to help with playability.

A deck is packaged as 100 cards.  These come from a single element, though may include neutral cards too.  Each deck includes a complete set for that element.

Glass counters are helpful to play as cards may generate tokens.

## Reprints

Cards within the catalog can be reprinted on request for a reasonable fee.  Cards are also available online for individuals to print.

## Crowd Sourcing

New cards can be created online and printed with the JRUCS templates.  We encourage you to share them back so others can use them too.

## The Mutability of Rules

Everything that follows is a standard structure.  Particular games or cards can modify it.

## Deck Construction

A game is played with:

* 50 cards
* 5 card hand
* 1 card draw
* 10 life

## Point System

There is a point system to build deck.  Each player has a maximum of 100 points.  Some cards have negative point values because they're terrible.  The point system is not printed on the cards but maintained online, so values can be changed for balacing.

## Types

Card types are:

* Object
* Event

Cards may belong to one or more elements.  That is a property they have determined by the resources in their cost.  Different card sets have different elemental membership.

Initial ideas for elements and card sets are:

* **Alchemy** - Earth, Water, Air, Fire
* **Gods** - Peaceful, Violent and Mystic
* **Legends of Arthur** - Medieval fantasy with demons, dragons, vampires and knights.  Binary good and evil conflict.
* **The Hot Gates**
* **Kingdoms** - Animal, Plant, Fungi, Protist, Archaea
* **Expats** - 1920 Paris

## Turn Structure

1. **Untap** - Untap your cards.
2. **Overhead** - Pay overhead costs due.
3. **Barter** - Trade tokens with other players.
4. **Draw** - Draw a card from your deck.
5. **Cast** - Play objects and events.
6. **Combat** - Events may be played at any point.  Declare attackers.  Opponent declares defenders.  Damage is dealt and creatures die.
7. **End** - Damage done to creatures heals.  Discard down to maximum hand size.

## Resolution

You can only create an object on your turn.  Events can happen at any time.  They can be cast in response to both objects and events.

Resolution can follow one of three models:

1. Simultaneous
2. Queue - LIFO
3. Stack - FIFO

## Hand Size

Maximum hand size is 5.

## Tapping Objects

If an object with a countinous effect becomes tapped that effect ceases until it is untapped.

## Winning

Win conditions vary by game.  Some examples are:

* If any player ends a phase with no life they lose.
* If any player must draw a card but cannot:
  * That player loses.
  * The player with the most life then wins.
  * The player with the most cards in play wins.
* The first player to 100 life wins
* The fist player to have 20 cards in play wins.

## Loops

* Ko - If a player repeats the same step, the game is a draw.
